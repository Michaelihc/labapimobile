# LabAPIMobile

A server plugin framework project for the Carl Mod mobile version of SCP: Secret Laboratory.

## References

The supplied packages live in `.refereces/`:

- `004vser_完整服务端_2026-10-05.zip` — Windows Mono server.
- `Carl Mod - 0.0.4.apk.1` — Carl Mod Android client.
- `scpsl.apk.1` — alternate Android client.

`.refereces/scpsl-metarepo/` is a Windows junction to the existing SCP:SL metarepo:

`<scpsl-plugins-metarepo>`

Read its [reference instructions](.refereces/scpsl-metarepo/.references/AGENTS.md) before using the official LabAPI source, native server decompilation or EXILED source mirror.
